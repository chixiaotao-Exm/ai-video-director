# S05：同步、口型检查与成片

状态：严格同步、混音和成片执行器及真实 FFmpeg 集成已完成；基于 AI 动作输出的完整唱跳合成待验收（2026-10-21）。依赖：S03、S04。目标：完成第一个可验证的短片后端闭环。

正式混音器已将10秒真实SeedVC转换人声与同源伴奏合成48kHz双声道、480000采样点，未拉伸，实测峰值-2.360223dB。证据为 `data/t21-performance-runtime-20261021/performance-real-mix-evidence.json`。完整技术MP4已由正式合成器产出：`data/t21-performance-runtime-20261021/performance-real-final-20261021-123347/final.mp4`，160帧、16fps、480×832，H.264与48kHz双声道AAC均整10秒，AI标识和metadata已核验。视频来自真实Wan生成，音频来自正式SeedVC换声混音，未使用原舞蹈画面替代。开头约1秒人物出画，目标音色、手指与口型尚未通过人工审阅，故这只是独立技术样片，不代表S05质量验收或主项目队列发布闭环已完成。

## 工作包

1. 用统一时间轴对齐动作视频、新人声、原伴奏，校验起点、中间和终点的节奏锚点。
2. 输出原片/新片对比和口型检查结果；人物全身小脸时不强行做不可靠的局部修正。
3. 对需要修正且素材适合的近景片段提供可选口型任务；修正节点同时依赖基础视频和新人声，检查身体动作是否被改变。
4. 使用 FFmpeg 完成视频选择、混音、可选字幕与既有成片标识设置；相关输出参数纳入缓存快照。
5. 区分技术同步与感知口型：时间轴机械误差目标不超过选定输出帧率的一帧，口型/踩点另外人工验收。
6. 实现源轨保留、产物完整性检查、失败重试和回退，并验证主计划中的增量矩阵。

## 产物

- 新人物、新声音、新场景的短片 MP4。
- 同步指标、原/新预览、选定的视频/人声/伴奏版本记录。
- 缓存、失效、回退、取消和 FFmpeg 真实媒体回归测试。

## 验收

- 原歌词/旋律/动作节奏保持，声音和动作没有明显错拍，口型逐段确认。
- 无截断、丢音轨、爆音或不必要的重复压缩；播放/导出正常。
- 换音色复用基础动作视频，但重做同步检查及已启用口型修正；换场景复用人声。
- 只调伴奏音量不调用模型；取消后不发布不完整最终版本。
- 达成本阶段才称为“短片后端闭环完成”，不以单个模型输出代替整段验收。
