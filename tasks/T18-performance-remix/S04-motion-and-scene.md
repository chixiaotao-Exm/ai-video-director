# S04：目标人物、舞蹈动作与新场景

状态：正式后端、快照、恢复与时间轴适配已接入；真实动作模型效果待验收（2026-10-21）。依赖：S02。目标：生成保留参考动作的新人物、新场景视频。

正式工作流配置会冻结图、模型/节点版本、ComfyUI连接与参数。远端prompt提交前写入恢复journal，重试先查已有prompt，不重复提交。显式`input_sampling`按源PTS采样，记录源帧/原生帧全部映射；仅对声明且计数、PTS、时长都符合的输出尾补帧执行剔除，不隐式加速或拉伸。

超时、取消或本地进程失败后，父 worker 先只读核验冻结服务器的 history/queue。不能确认原 prompt 已终止时，永久隔离 GPU lane，并保留 server、prompt 和 journal 的恢复指引；不向共享 ComfyUI 发送全局 interrupt。独立 CLI 被操作系统强杀后，过期的远端视频 lease 也不能自动释放 GPU。只有核实关联远端执行已结束、所有旧 worker 已停机后，才可执行独占人工恢复。普通本地作业保留原有过期恢复语义。

真实600@60竖屏源已通过160+1@16采样复验（1.889秒、10.0625秒输入），并修复160项FFmpeg选择表达式的解析深度问题；最终合同为160@16的10秒。实际ComfyUI 0.42已验证31节点候选图schema及CPU媒体I/O；四个官方模型的完整 SHA-256 已通过，Wan先产出1.35秒、480×832、81帧@60的换人换景短片，随后完成下述正式10秒技术验证。短片采用独立的扩边参考副本；正式适配器只执行一次已声明的裁尾。证据见`data/t21-performance-runtime-20261021/wan-real-short-attempt-2-visual-review.json`、`wan-formal-sampling-validation-attempt-2.json`、`wan-real-object-info-validation.json`、`wan-official-models-manifest.json`和`comfy-cpu-media-smoke.json`；旧 `wan-real-prompt-validation-pending-models.json` 仅保留当时模型未齐的历史拒绝证据。

工作流可显式声明 `reference_image_fit`，以 FFmpeg 等比缩放并居中补边，完整保留参考人物的头脚。原场景版本不变，另存输入副本并记录原图/副本哈希、尺寸、位置、缩放舍入与 FFmpeg 版本；重启恢复核对并复用同一副本，不重新上传。未声明时保持旧快照和指纹；口型阶段因无参考图输入而明确拒绝该配置。

完整10秒正式适配器现已实际运行：原生161帧全部PTS精确等于`i/16`，耗时1505.253秒；MP4 edit-list尾时长量化使attempt1本地导出失败，修复后从保存的原生history/raw和同journal本地恢复，新增推理0，导出160帧、16fps、480×832、整10秒。原始容器duration与完整逐帧presentation endpoint同时保留，不扩大PTS/帧数容差，不删除失败记录。证据为 `wan-formal-ten-context21-uncached/attempt-2-recovery-result.json`。输出0/6帧大幅出画、12帧偏右、18帧恢复居中。原上传素材自身在第3帧（0.05秒）从居中突变至右缘；16fps原生输入仅第0帧保留居中姿态，后续第1–9帧本就靠右。未发现准备、横向裁剪或PTS映射偏移，不能把整段开头判断为无依据漂移；生成没有保住源第0帧的姿态，仍属未解决的质量缺陷。S04视觉验收未通过，不能把适配器技术成功当作全身构图保证。

## 工作包

1. 在角色库选择已确认的正脸/全身参考，生成或选定与场景、服装一致的人物参考帧。
2. 使用 S01 验证过的动作视频驱动工作流；只添加该工作流实际需要的姿态、面部、遮罩或重定向预处理。
3. 保存动作源区间、人物参考版本、场景描述、视角、模型/工作流版本、种子、帧数、FPS、分辨率和必要控制参数。
4. 实现提交、进度查询、输出验证与下载；将 ComfyUI prompt_id 或服务任务 ID 持久化，恢复时先查询已有任务。
5. 默认采用接近参考视频的镜头视角，避免第一版同时引入大幅自由运镜；允许先重做一段预览。
6. 区分可重试错误、无效输入、资源不足；本地取消和远端任务取消能力分别记录，不能假装外部已停止。

## 产物

- 真实工作流模板、环境配置及动作生成后端。
- 无声视频版本、缩略图、原/新画面同步对比信息。
- 固定人物+新场景的重复运行样片。

## 验收

- 身份、服装和场景符合输入；目标关键动作与参考对应。
- 检查快速转身、交叉手臂、遮挡、脚部接地和背景稳定，记录不支持的输入条件。
- 视频时长/帧数/FPS与 S02 时间映射一致；不把截断或慢放造成的错拍当作成功。
- 同配置缓存复用；换场景或人物重建视频，不重做已确认的歌声。
- 重启后可恢复既有远端任务，下载到不可变版本目录，URL过期或输出缺失有可操作错误。
