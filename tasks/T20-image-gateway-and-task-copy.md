## 修复

- 在远端配置原有 `requests` 节点开启 5 秒流式心跳、首个结果前心跳和 5 秒非流式保活；`bootstrap-retries=0`。保留 Nginx 配置和私有绑定端口。
- 远端 `routing.retry` 从额外重试 20 轮、最多 20 份凭据改为 `request-retry=0`、`max-retry-credentials=1`，原间隔 3 秒不变。这个设置影响整个网关：停止该层额外轮次和跨凭据重发；应用自己的分类重试仍保留。6 份凭据 JSON 的安全统计未发现重试覆盖，配置未声明目标模型别名池。不将这些统计扩大解释为运行态的所有上游行为保证。
- 两次远端变更均先在受限备份目录保存原配置，热加载日志均成功。将两个目标片段还原后与最初备份逐字相同，未修改其他配置。没有记录登录密码或 API 密钥。
- GPT 新图生成使用流式，只接受完整完成事件，部分图像与心跳不作成功；收到完整图像后立即结束读取。参考图编辑在提交前选择完整 JSON 响应，避免当前网关编辑流返回空事件；不在失败后自动切换格式并再次付费提交。两条路径均关闭 SDK 隐式重试。
- 图像提交/读取遇到传输故障、524 或流缺少完成事件，标为 `image_outcome_unknown` 并停止自动重发。明确的认证、参数、额度和限流错误保留原分类；普通 LLM 超时仍按原策略处理。
- 图像请求派发前短事务记录实际 provider/model，失败也保留证据。
- 最近任务、全局队列、唱跳任务支持复制单项诊断、本列表全部、完整错误。复制失败时提供纯文本手动窗口；轮询按 ID 更新，选中文字期间延后替换，保留详情展开状态。
