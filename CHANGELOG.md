# Changelog

## 0.2.0 — 2026-10-20

- Vue 3 studio shell, native dashboard, appearance gallery, performance planner and software version center.
- Four persistent visual templates: Midnight Studio, Liquid Glass, Acid Edit and Sunday Editorial; responsive layouts and reduced-motion support.
- Existing project, chat, storyboard, assets, queue, settings and diagnostics remain available inside the new themed workspace.
- Cited singing/dancing model recommendations with API, hybrid and local GPU routes. Plans can be saved/exported; the recommended music/motion APIs are **not yet generation adapters**.
- Read-only local Git status/history/tags, GitHub CI and contribution templates.
- Chat send failures restore drafts before retrying history; attachment formats match the upload API.
- Chat composers remain inside desktop/mobile viewports, and deleting a project clears stale navigation references.
- Project deletion acquires its SQLite write lock before checking running work; web search uses the same estimate, budget confirmation and usage accounting as chat.

## 0.1.0

Initial project state, asset consent, persistent workers, incremental generation, director tools, local browser interface and offline FFmpeg demo. Milestone history is recorded in `docs/PROGRESS.md`.
